# Filosofía de Diseño

> Este documento no describe componentes, colores o tecnologías. Describe la intención emocional detrás de S&A. Todo cambio visual debe respetar esta filosofía.

---

# El propósito

S&A no busca impresionar.

Busca emocionar.

La interfaz nunca debe ser el centro de atención.

Debe desaparecer para que únicamente permanezcan los recuerdos.

El usuario nunca debería pensar:

"Qué bonita es esta interfaz."

Debería pensar:

"Qué bonito fue ese momento."

La diferencia es enorme.

---

# El silencio visual

Uno de los principios más importantes del proyecto es el silencio.

Una interfaz silenciosa es aquella que no exige atención.

No distrae.

No interrumpe.

No compite.

Simplemente acompaña.

Cada componente debe transmitir calma.

---

# La fotografía es la protagonista

La fotografía siempre tiene prioridad sobre cualquier otro elemento.

Si existe una decisión entre destacar un botón o destacar una imagen.

Siempre debe ganar la imagen.

Las fotografías cuentan la historia.

La interfaz únicamente las presenta.

---

# El tiempo

S&A no organiza fotografías.

Organiza recuerdos.

Por esa razón el Timeline es el corazón del proyecto.

El usuario no navega carpetas.

Recorre momentos.

Cada desplazamiento representa un viaje por una historia.

---

# La sensación de calma

Todo movimiento debe transmitir tranquilidad.

Nunca urgencia.

Nunca ansiedad.

Nunca velocidad.

Las animaciones existen para conectar dos estados.

Nunca para llamar la atención.

---

# El ritmo

La aplicación tiene un ritmo.

Debe sentirse pausada.

Respirar.

Cada sección debe tener suficiente espacio.

Cada fotografía debe tener tiempo para ser observada.

Nunca llenar la pantalla únicamente porque existe espacio disponible.

---

# La simplicidad

La simplicidad no significa ausencia de trabajo.

Significa eliminar todo aquello que no aporta valor.

Cada botón debe justificar su existencia.

Cada icono debe resolver un problema.

Cada línea debe tener un propósito.

---

# La emoción

El objetivo del proyecto no es mostrar fotografías.

Es provocar recuerdos.

Una buena experiencia hará que el usuario permanezca observando una fotografía más tiempo del necesario.

Ese es el éxito del diseño.

---

# Inspiración

Apple Photos representa una referencia importante.

Pero únicamente desde la filosofía.

No buscamos copiar interfaces.

Buscamos aprender de sus principios.

La identidad visual de S&A debe ser propia.

---

# El color

El color principal es el vinotinto.

No debe utilizarse como protagonista.

Debe aparecer como una firma.

Como un detalle.

Como una identidad.

Nunca saturar la interfaz.

---

# La tipografía

La tipografía debe transmitir cercanía.

Debe ser elegante.

Moderna.

Legible.

Nunca utilizar tipografías decorativas.

Las palabras son recuerdos.

Deben poder leerse con facilidad.

---

# El espacio

El espacio vacío no está vacío.

Está permitiendo respirar al contenido.

Nunca reducir márgenes únicamente para mostrar más elementos.

La comodidad visual tiene prioridad.

---

# Las sombras

Las sombras deben ser discretas.

No buscamos dramatismo.

Buscamos profundidad.

El usuario no debería notar las sombras.

Simplemente sentir que los elementos pertenecen al mismo espacio.

---

# El movimiento

Toda transición debe sentirse inevitable.

Como si el siguiente estado siempre hubiera estado esperando.

Las animaciones nunca deben sorprender.

Deben resultar naturales.

---

# La escala

Las fotografías grandes generan presencia.

Las fotografías pequeñas generan información.

S&A prioriza la presencia.

---

# El contenido

La aplicación no crea recuerdos.

Los conserva.

Todo el diseño debe respetar esa responsabilidad.

---

# Qué NO queremos transmitir

No queremos parecer:

- una red social
- un dashboard
- una aplicación empresarial
- un portafolio
- un explorador de archivos
- una tienda
- un blog tradicional

---

# Qué queremos transmitir

Queremos que el usuario sienta:

- calma
- nostalgia
- cercanía
- intimidad
- elegancia
- calidad
- cariño
- permanencia

---

# La experiencia ideal

La experiencia perfecta sería que el usuario olvidara completamente que está utilizando una aplicación.

Que únicamente sienta que está recorriendo una colección de momentos importantes.

Si conseguimos eso.

El diseño habrá cumplido su objetivo.

---

# Regla de oro

Antes de aprobar cualquier cambio visual.

Preguntarse:

¿Este cambio hace que los recuerdos brillen más?

Si la respuesta es no.

Debe replantearse.

Toda decisión de diseño debe proteger el contenido, nunca competir con él.

---

# Estado del documento

Este documento representa la filosofía oficial de diseño de S&A.

Debe evolucionar únicamente cuando cambie la visión del producto.

Nunca por preferencias personales o modas de diseño.
